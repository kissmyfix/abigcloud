# **Reference**

The material this project runs on is not linkable web content. It is council packets, property assessments, federal tax filings, legislative archives, and audio recordings, most of which nobody has put online in any usable form.

So it lives in the open. Every document an investigation cites is published in full at [Sources](/sources/), and citations name the document by its path in the research archive. There is no separate bibliography to drift out of date, because the link is the citation.

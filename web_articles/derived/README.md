# web_articles/derived/

## Purpose
Plain-text extractions of the PDF reports held in the parent directory, so long documents
can be searched and passages located quickly.

## Contents
- `report-gallatin-idb-leon.txt` — Lilibeth Leon's TCED capstone, August 2024. The single
  most quoted document in the investigation. See `the_players/lilibeth_leon.md` and
  `angles/leon-exhibit-a.md`.
- `report-gallatin-idb-bates.txt` — the Bates capstone.
- `report-gallatin-idb-isbell.txt` — the Isbell report.
- `pilot-tldr-utk.txt` — the UT PILOT summary.
- `pdf-index.csv` — kind, pages, and trust rating per source file.

## Source Type
**Derived.** Machine output from `files/bin/pdf-extract.py`. Regenerable, never
hand-edited. See the `derived/` convention in `files/DATA_MAP.md`.

## Handling Instructions
- **Quote from the PDF, cite the PDF, with a page number.** These documents are going to be
  quoted in published work and challenged on the quotations, and a page-anchored citation
  to the author's own report is the strongest form the claim can take.
- The parent directory is a holding pen with a do-not-browse rule. This subdirectory
  inherits it: come here for a specific document, not to see what is around.
- Search here freely once sent.

## Notes
The capstones are the participants describing their own mechanism voluntarily, which is
what makes them worth this treatment. They are secondary as publications and close to
primary as admissions.

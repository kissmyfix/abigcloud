Three pie charts per corp, fixed left-to-right order: PILOT → County, PILOT → City, Rent. Each pie is sliced by year, wedge size = dollar amount that year — so Woolhawk's PILOT-City pie should be dominated by 2024/2025. Categories with no payment ever reported render as one solid striped "No Data Reported" circle instead of an invisible sliver. Beretta gets a third state — striped warning-yellow "NO INFO" — marked "N" (not verified by the county assessor) in the state record, with payment amounts withheld or unreported; either way it's not a confirmed zero, and that's a different fact from Bradford/Woolhawk's confirmed $0s. Key with per-year amounts sits under each pie.

# tn_comptroller_pilot_reports/hamilton_county/

## Purpose
Hamilton County's PILOT filings, 2014 to 2025, held as the **large-metro control group**.
Chattanooga's IDB is the comparison that matters most: it has used an explicit "economic
development payment" clause since 2008 and has a standing practice of remitting the
schools' full share. It is the example of a board doing openly what Gallatin's did
ambiguously.

## Contents
- `2014-pilot-hamilton-county.pdf` through `2022-pilot-hamilton-county.pdf` — one report
  per year.
- `2023-2025-pilot-hamilton-county.ods` — the later years as a spreadsheet.

## Source Type
**Primary Source.** Tennessee Comptroller of the Treasury PILOT registry filings.

## Handling Instructions
- Built into `../derived/hamilton-county-pilot-master-2014-2025.csv` by
  `files/bin/build-hamilton-master.py`. Use the master CSV for analysis and come back here
  for the source page behind any figure.
- A baseline, not an allegation. Nothing here is a claim about Hamilton County.
- Self-reported by the boards. It records what was told to the state.
- Reported `$0` and NO INFO are different states. Do not merge them.
